# Duolingo Chess reference

Capture of a Duolingo Chess lesson, in order, from a phone screenshot
session. 130 frames live in [frames/](frames/). [SOURCES.tsv](SOURCES.tsv)
maps each `NNN.png` back to the original filename.

Read [PATTERNS.md](PATTERNS.md) before opening frames. That file is the
pattern list. Open a cited frame only when the screen you are judging is
that kind of step.

These images are a design reference for how a lesson feels. They are not
app assets. Do not add `frames/` to `pubspec.yaml`. Do not ship the owl,
Oscar, the green palette, or Duolingo copy. Translate the loop into the
Theme and mascot already in [the design record](../../design-record.md).
