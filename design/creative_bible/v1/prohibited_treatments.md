# Prohibited treatments (v1)

Short list. If a frame matches any item, reject before approval.

1. **Language-app / Duolingo imitation** — mascots, owl energy, candy palettes,
   bubbly celebration storms, streak-as-character, cartoon "you got it!"
   excess.
2. **Archetype-as-appearance** — dressing or posing a character so they "look
   like" a nit, LAG, TAG, maniac, station, or any tendency label. Visual
   identity ≠ playing style.
3. **Protected-class stereotyping** — ethnicity, nationality, gender, age,
   disability, religion, or body type used as shorthand for skill, aggression,
   honesty, or intelligence.
4. **Casino carnival** — neon glow stacks, jackpot kitsch, champagne spray,
   chip fountains as default reward language.
5. **Horror / threat** — menacing villains, intimidation poses, violence
   metaphors for "punishing" mistakes.
6. **Flat purple-on-white AI-default look** — unrelated gradient themes that
   break the navy / felt / gold system.
7. **Illegible silhouette** — characters that collapse at phone thumbnail size
   or rely on tiny facial detail to read.
8. **Inline archetype badges on characters** — no "NIT" / "LAG" nameplates on
   cast portraits (table UI tendency chrome is separate and must stay off cast
   art).
