# What to take from Duolingo Chess

Inspiration for how a lesson teaches, not a skin to copy. Poker keeps the
dark felt theme, Rex, and the shared poker table. The loop below is what
a learning screen has to do.

Frames are in [frames/](frames/), capture order.

## Loop

1. **One step, one job.** A prompt, the board, and one way to answer.
   Frame `001.png`.
2. **The board is the hero.** It fills the middle. Chrome is a thin top
   bar: close, a segmented lesson bar, and lives. Frame `001.png`.
3. **Answer in the world when you can.** Tap a square, a piece, or a
   card. Use big choice buttons only when the answer is a label.
   Frames `035.png`, `070.png`, `110.png`.
4. **Correct is a beat, not a new page.** The mascot celebrates, a short
   line says why, one button continues. Frame `002.png`. A capture or a
   pot won gets the same beat on the board. Frame `050.png`.
5. **Wrong is a beat too.** The mascot shows the mistake, the right idea
   is visible, lives tick, and the next button is still one tap.
   Frame `090.png`.
6. **Help is a sheet, not a second lesson.** A hint slides over the
   board and dismisses back to the same step. Frame `020.png`.
7. **The lesson pays off.** XP, a goal bar, and one continue. Stats are
   the reward, not a report. Frame `117.png`.
8. **Home is a path.** Nodes, a character standing on the next one, a
   section chest. The current lesson is obvious. Frame `125.png`.
9. **A section ends as a ceremony.** Character, title, one button.
   Frame `128.png`.

## Poker translation

| Their beat | Ours |
| --- | --- |
| Chessboard | The lesson stage. A hand step is the full poker table, with fewer seats or a shorter board. A step with no hand keeps the same frame and does not invent a mini table. |
| Oscar | The coach band: mascot box (104×118) and one speech bubble. Expression follows the beat (thinking, happy, wrong). |
| Hearts | Lesson lives already on the runner. They move when the answer is wrong. |
| Green buttons | Theme elevated button. Do not introduce a second green. |
| XP burst | The lesson result shows XP for this lesson before Home. |
| Path nodes | Home course path. The next lesson is the one marked node. |

A learning screen that is a form, a wall of text, or a silent pop back to
Home misses this loop. File that against the Gamified learning section of
the design record.
